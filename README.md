# HelpHub

Small, runnable examples for practical development questions. Each example explains its scope, how to run it, and what was checked.

| Example | Use it to |
| --- | --- |
| [Calculator input](examples/calculator-input) | Retry invalid console input while keeping fractional arithmetic. |
| [Custom Lisp definitions](examples/custom-lisp-tags) | Navigate custom Common Lisp and Elisp declarations from Treemacs. |
| [FeatherScroll navigation](examples/feather-snap-scroll) | Scroll to sections and settle gradually after wheel input. |
| [Paragraph classes in Delta](examples/paragraph-class-delta) | Keep paragraph classes through editing and JSON export/restore. |
| [Required Quill content](examples/required-quill-content) | Reject empty code blocks and submit meaningful content without changing it. |
| [Article equations](examples/article-math) | Save, render and reopen native Quill formulas alongside article content. |
| [CSV to RDF checks](examples/csv-rdf-checks) | Diagnose failed expressions before producing the intended RDF graph. |
| [Accessible name rules](examples/accessible-name-rules) | Compare the naming rules applied to menu items built from divs, buttons and links. |
| [TypeScript story](examples/typescript-story) | Scaffold, build, play and revise a terminal story without writing Chord source. |
| [.NET test runtimes](examples/side-by-side-tests) | Build an older target with a newer SDK and run its tests in a separate root inside a Conda environment. |
| [TexSoup node identity](examples/tex-node-identity) | Recognize the same parsed expression reached through different navigation paths. |
| [Condition expressions](examples/condition-grammar) | Keep one expression grammar while distinguishing struct literals from condition bodies. |
| [Fixed model snapshot](examples/model-snapshot) | Retain exact Stanza resources and model bytes, then run the verified local pipeline offline. |
| [Cell row selection](examples/row-selection) | Toggle complete rows from data cells while keeping ranges, dragging and subsequent selection. |
| [Image size checks](examples/image-size-checks) | Limit new Quill images across file and HTML paste routes, then export and restore checked Delta content. |
| [File read policy](examples/file-read-policy) | List mock files while testing one async read failure through the existing file-system interface. |
| [Country input triggers](examples/country-input-triggers) | Refresh the intended city options from country inputs with the same binding in two htmx versions. |
| [Postal request reason](examples/postal-request-reason) | Refresh postal hints on country changes and validate on focusout while keeping strict CSP. |
| [Named cache backplanes](examples/named-cache-backplanes) | Keep default and named FusionCache instances coherent across replicas using separate native adapters. |
| [Lambda metric tests](examples/lambda-metric-tests) | Restore metric assertions and configure local tracing before pytest starts. |
| [MailFlow locale build](examples/mailflow-locale-build) | Register a supplied translation in the native language menu and build a personal frontend image. |
| [Date picker padding](examples/date-picker-padding) | Add editor insets to one FlatLaf SwingX date picker and reapply them after a theme update. |
| [Runtime CSV headers](examples/runtime-csv-headers) | Select export headers at runtime while retaining CsvHelper generated record serialization. |
| [Marker channel names](examples/marker-channel-names) | Check Backsub row indexing, repeated reference labels and explicit per-cycle background names on synthetic data. |
| [C++ functions in Sere](examples/cpp-functions) | Bind simple C++ functions and build a native Sere application with matching types. |
| [Shared client header](examples/shared-client-header) | Reuse an HTTP header default across Connect clients while preserving each call’s override and suppression. |
| [YAML in plain HTML](examples/yaml-classic-script) | Load the official browser file with a classic script tag and convert YAML without a bundler. |
| [Push options](examples/push-options) | Send ci.skip from a Lazygit custom command while retaining ordinary push behavior. |
| [Availability classes](examples/stock-by-class) | Map class tokens to availability while delivery text and quantities vary. |
| [Rust JVM logging](examples/jvm-logger) | Convert Rust strings and launch a standalone JVM program with an external SLF4J provider. |
| [Exact palette PNG](examples/exact-palette-png) | Export a bounded 4-bit texture with an exact palette, unchanged pixels and a file-size limit. |

The examples are free to use under the MIT license.
